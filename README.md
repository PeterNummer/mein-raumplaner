# 🏠 Raumplaner

Ein interaktiver Raumplaner als reine HTML-, CSS- und JavaScript-Web-App.

Die Anwendung benötigt keinen Server und kann direkt über GitHub Pages betrieben werden.

---

## ✨ Funktionen

- 🏠 Interaktiver Grundriss
- 🪑 Viele verschiedene Möbel
- ➕ Möbel hinzufügen
- 🖱️ Möbel per Drag & Drop verschieben
- 🔄 Möbel drehen
- ✏️ Position und Größe bearbeiten
- ⧉ Möbel duplizieren
- 🗑️ Möbel löschen
- 💾 Planung speichern
- 📂 Planung laden
- ↺ Raum zurücksetzen
- ⌨️ Tastatursteuerung
- 📱 Responsive Oberfläche
- 🌐 Funktioniert auf GitHub Pages
- 💻 Funktioniert offline, nachdem die Seite geladen wurde
