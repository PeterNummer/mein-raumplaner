# 🏠 Mein Raumplaner

Ein interaktiver Raumplaner für den Browser.  
Mit ihm können Möbel in einem Raum platziert, verschoben, gedreht, dupliziert und gelöscht werden.

## ✨ Funktionen

- 🛏️ Verschiedene Möbelstücke
- 🖱️ Möbel per Drag & Drop verschieben
- 🔄 Möbel drehen
- 📐 Position und Größe bearbeiten
- 📋 Möbel duplizieren
- 🗑️ Möbel löschen
- 💾 Raumplanung speichern
- 📂 Gespeicherte Raumplanung laden
- 🔄 Raum auf Standard zurücksetzen
- ⌨️ Tastatursteuerung
- 🏠 Raum mit schräger Wand
- 🚪 Tür
- 🪟 Fenster
- 🗄️ Fester Einbauschrank in der schrägen Wand
- 🌐 Läuft direkt im Browser
- 📱 Responsive Oberfläche
- 💻 Funktioniert ohne Server und ohne Datenbank

## 🤖 Hinweis zur Erstellung
